# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub Issues or Discussions.

Report security vulnerabilities privately to:

support@twin.rent

Please include:
- a description of the vulnerability,
- affected component or version,
- steps to reproduce,
- potential impact,
- any suggested mitigation.

## Response

We aim to acknowledge security reports within 5 business days.

We will investigate the report, assess severity and coordinate remediation where appropriate.

## Responsible Disclosure

Please do not publicly disclose a vulnerability before we have had a reasonable opportunity to investigate and address it.

Do not intentionally access, modify or destroy data belonging to other users or systems.

## Scope

This policy applies to the Twin Runtime open-source project and its official repositories maintained by the twin-runtime GitHub organization.

Third-party adapters, forks and external services may have their own security policies.

## Supported Versions

Twin Runtime is currently in early development.

Security support applies only to the latest version available from the official repository.
